# Видеообзор IT Lab 3D

[Открыть видео — MP4, 59 секунд](IT-Lab-3D-demo-59s.mp4). Если GitHub не показывает проигрыватель, нажмите Download raw file.

Видео записано с работающего приложения. В нём показаны выбор компонентов материнской платы, объяснения их назначения, туториал запуска, установка RAM/SSD/GPU с успешным завершением сборки и режим самостоятельной диагностики. В конце показано текущее состояние наставника: встроенные подсказки работают, живая модель пока не подключена.

1920 × 1080, H.264/AAC, русская синтезированная озвучка и встроенные подписи. Отдельные [субтитры SRT](IT-Lab-3D-demo-59s.srt) и [текст озвучки](IT-Lab-3D-video-script.txt) приложены для удобства.

По приложению 2, п. 2.2 предоставленного положения Codex Challenge версии 1.7 достаточно видео до одной минуты **или** презентации до двух слайдов. Этот файл укладывается в лимит видео. Он является обзором продукта и не подтверждает проведение мероприятия по распространению опыта.
